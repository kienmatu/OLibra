# Six UX Gaps Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the six defects specified in `docs/superpowers/specs/2026-08-11-ux-gaps-design.md` — book comments, manager→shelf link, Nhận trả selection, portal signed-in rows, header links, site-wide footer.

**Architecture:** Five of the six are chrome changes to three shared components plus two new route layouts. The sixth wires an existing, fully-tested domain command (`createComment`) to a new server action and a new section on the book detail page. One shared prerequisite — the viewer's shelf memberships — lands first because two items need it.

**Tech Stack:** Next.js 16 App Router, React 19 server components, Tailwind v4 (CSS-first `@theme`), PostgreSQL via `postgres`, Vitest, Bun.

## Global Constraints

Copied from `AGENTS.md` and the spec. Every task's requirements include these.

- **Bun only.** `bun run check`, never npm/pnpm/yarn.
- **Vietnamese with full diacritics** for every user-facing string. Never English, never lorem ipsum.
- **Status is never colour alone** — icon + Vietnamese word + colour, together. Use `StatusBadge`/`StatusPanel` for the six copy states, `Pill` (icon and label both required) for anything else.
- **One primary action per screen.** Solid terracotta appears once.
- **Touch targets ≥ 44px**, primary buttons 56px, nothing closer than 8px.
- **No shadows, no gradients, no glassmorphism.** 1px hairline borders and flat tonal layers.
- **Serif only for book titles**, and only via `BookTitle`.
- **Check `src/components/ui` before writing a new component.**
- **`bun run check` must pass before every commit** (typecheck + lint + format:check + test). `db-test` must be running.
- Vitest has **no `@/` alias** — files under test import relatively (see the note at the top of `public-header.tsx`).
